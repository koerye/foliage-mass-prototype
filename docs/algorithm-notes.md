## 从冠形实验到枝叶薄片

早期松树试过随机叶片、密集叶簇和封闭枝叶体块。随机叶片容易形成刺球，密集叶簇的细节偏碎，封闭体块虽让层级清楚，却像一层层圆垫，削弱了枝叶从主枝向外生长的方向感。工程指标和浏览器功能都通过时，冠形仍可能偏离目标。

随后把验证单位缩小到一根松树枝。先用代码设计一组可辨读的叶束，再比较三种几何表示。

| 方案 | 几何表示 | 对比重点 |
| --- | --- | --- |
| A | 整枝程序轮廓与 Alpha 面片 | 轮廓清楚，侧视体积弱 |
| B | 带弯曲、渐薄边缘和浅厚度的枝叶薄片 | 多角度可见体积，能区分上下表面 |
| C | 程序叶簇贴图与交叉面片 | 用简单几何获得方向覆盖，斜视会显出交叉关系 |

三种方法先分别组装三层树冠，再比较七层版本，后续选 B 作为基线。 [单枝对比](experiments/branch-sheets/branch-comparison.png) · [三层](experiments/branch-sheets/tree-3-tiers.png) · [七层](experiments/branch-sheets/tree-7-tiers.png)

## 通用薄片如何生成

1. 用沿生长轴排列的宽度控制点定义轮廓。叶束的起点、朝向、长度和宽度决定空间位置，侧向摆动和轮廓起伏产生有方向的边缘。
2. 沿轴生成网格，用隆起、下垂和横向倾斜形成浅曲面。上下面分别建网，两面的距离向边缘收薄。程序生成的裁切贴图带有绿色渐变和沿叶束展开的笔触。
3. 组装树冠时先安排主轮廓，再用中型叶束和少量边缘细节建立节奏。分枝位置、朝向和遮挡决定冠形，色调与上下表面材质负责可读性。 [共享薄片源码](src/foliage-sheets.ts)

## 松树 · 同一枝叶模板的三种树形

沿弯曲主干放置七层枝叶，每层四个模板实例。相邻层改变方位、锚点高度和俯仰，最上两层用短枝和上收的姿态衔接。每根枝有最大外伸范围，通过模板最远顶点约束实例缩放。叶背使用单独的材质色调。

| 树型 | 构图规则 |
| --- | --- |
| 标准型 | 下层舒展，往上逐层收窄 |
| 茂密型 | 分层更紧凑，枝条较短，通过邻层遮挡提升丰满度 |
| 古老型 | 主干弯曲，枝长不对称，部分枝条自然下垂 |

三种树形共用已验证的 B 枝叶模板。工作台预览使用实例化渲染，GLB 导出使用普通网格节点。标准型预览实测约 69 万三角面、102 个 Draw Calls（含地面），属于高细节样本。 [三型实拍](experiments/branch-sheets/B-three-profiles.png) · [松树构图源码](experiments/branch-sheets/b-study.ts)

## 阔叶树 · 多级分枝与树冠簇

阔叶使用独立的生长规则。树干、主枝和次枝由三次贝塞尔曲线描述，木质网格沿曲线扫描并逐渐收细。次枝从主枝曲线上的接点伸出，每个冠簇锚定在一条真实枝条的曲线上。全局包络支持 Round、Wide、Irregular，局部簇宽、高、深、方向、密度和颜色也分别控制。主枝可通过 JSON 单独覆写方位、角度、长度、曲率、粗细、子枝数和下垂。

| 树型 | 分枝与冠形 | Seed |
| --- | --- | --- |
| 圆冠型 | 七根主枝和向内上挑的次枝填充冠心，28 个簇形成宽而连贯的轮廓 | 4217、10429、27803 |
| 自然分枝型 | 五根主枝形成可读的主分叉，15 个簇分布在不同高度和深度，保留露枝和枝间空隙 | 7123、19277、31601 |

阔叶沿用薄片网格，新增宽阔叶簇、舒展枝叶簇和冠缘叶簇三种模板。叶束叠放的位置由分枝决定，叶片状笔触烘在程序贴图里。叶面法线向冠簇的外展方向适度偏转，使相邻薄片的受光更连贯。 [分枝源码](src/broadleaf/growth.ts) · [阔叶模板源码](src/broadleaf/foliage.ts)

## 验收与交付

- 现有工作台的「树型预设」可切换三种松树和两种阔叶。运行 `start.cmd broadleaf` 可直接进入，支持四个固定机位、枝干骨架、大型树冠和成品视图，以及 JSON、PNG 和 GLB。
- 阔叶六个样本均做了正面、45°、侧面和斜俯视检查，并实际导出、回读六个 GLB。圆冠约 4.47 万三角面，自然分枝约 2.27 万。生产构建和 33 项测试通过，松树原有实验对照图复渲染后逐字节一致。 [六种子对照](evidence/broadleaf/seeds.png) · [骨架与大型树冠](evidence/broadleaf/debug.png) · [GLB 与参数清单](report-stage4.md)
- 圆冠型的斜俯视仍可见局部枝隙，舒展型近看能辨认部分较大的薄片。两型的冠形已经能区分，参考图的美术完成度仍以实拍集中验收为准。

目前已经验证了「共用薄片与工具、按树种定义形态规则、按叶型选择表现模板」这条路线。松树的层级轮生和阔叶的分叉冠簇分别控制构图，共用的部分集中在薄片几何、预览和导出。
